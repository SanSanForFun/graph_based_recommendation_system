# Система рекомендаций фильмов на основе графов

Проект реализует систему рекомендаций, использующую
графовые алгоритмы для анализа взаимодействий
пользователей с элементами и генерации
персонализированных рекомендаций.

## Функциональные возможности

- Добавление предпочтений пользователей
- Генерация рекомендаций тремя методами:
    - **Коллаборативная фильтрация (CF)**
    - **k-ближайших соседей (k-NN)**
    - **Персонализированный PageRank (PPR)**
- Просмотр предпочтений конкретного пользователя
- Отображение статистики системы

## Запуск

### Требования

- Python 3.8+
- pip
- Redis

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/SanSanForFun/graph_based_recommendation_system
   cd graph_based_recommendation_system

2. **Создайте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Linux/MacOS

3. **Установите зависимости:**
    ```bash
    pip install -r requirements.txt

4. **Примените миграции базы данных:**
    ```bash
    python manage.py migrate

5. **Запустите сервер разработки:**
    ```bash
    python manage.py runserver

6. **Откройте в браузере:**
    ```bash
    http://127.0.0.1:8000/
